# TerraSpectra

## Project Title
Hyperspectral Crop Disease Forecasting

## Objective
To analyze hyperspectral crop data and develop
Machine Learning models for crop disease
detection and forecasting.

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Dataset Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Feature Engineering
5. Machine Learning Model Development
6. Model Evaluation

## Status
Project setup and development started.
